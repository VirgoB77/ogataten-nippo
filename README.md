# 大店立地法ウォッチ（偵察のしかけ）

**大きなお店ができる・なくなる**ことが、開店の8か月以上前にわかる。
その情報は**4か月で公開ページから落ちる**ので、毎日とっておくと、
そのうち誰も持っていない記録になる。

これはその第一歩で、**まだ集めるところまで行っていない**。
「それぞれの県・市のページが、機械で読める形かどうか」だけを確かめる道具。

## 姉妹サイト共通仕様

鯨屋が運営する姉妹サイト（大型店日報・開発系・競売統計・犯罪統計マップ）で共通して守る
決まりは、**[docs/kyotsu-shiyo.md](docs/kyotsu-shiyo.md) が唯一の正本**。

住所の正規化（`addr.py`）、個人情報の伏せ方（`privacy.py`）、横断用の `index.json`、
取得の作法、運営者情報の文面をここに置いている。
各リポジトリにコピーを置かず、この文書を読むこと。

## なぜ先に偵察するのか

いきなり全部を自動で集めようとすると、たいてい最初のページで詰まる。
ページの作りが県ごとにバラバラだからで、

- **HTMLの表**で出している … いちばん楽。すぐ自動化できる
- **Excel**を置いている … 実はいちばん楽なこともある
- **PDF**を並べている … 中を読むのに一手間かかる
- **上のどれでもない** … 自分の目で見に行くしかない

のどれなのかで、作るものが変わる。先に全部の判定を出してから決める。

## 使い方

### GitHub の画面から動かす（おすすめ・パソコン不要）

1. リポジトリの **Actions** タブを開く
2. 左の「**大店立地法の届出をためる**」を選ぶ
3. 右上の **Run workflow** を押す（見る場所を絞りたいときは `hyogo` か `osaka` と入れる。空なら全部）
4. 終わったら、実行結果の画面にそのままレポートが出る

**自分のパソコンでは何も動かさなくてよい。** 動かしているのは GitHub のサーバー。

あわせて**毎日朝7時（日本時間）に自動で走る**。走るたびにページの中身をそのまま
`data/raw/` に保存するので、**git の履歴がそのまま「いつ何が変わったか」の記録になる**。
差分を調べるしくみを自分で書かなくてよい。

### 2本のリポジトリ（生データの置き場）

（移行前。いまは鍵が無く、生データもこのリポジトリにあって1本で動いている。
移行の手順と順番は共通仕様9節）

生データ（取ってきたページ・Excel・PDF・OCR の結果・台帳）は、そのまま公開できるとは
限らないので、**private の収集用リポジトリ `VirgoB77/ogataten-nippo-raw`（金庫）** に置く。
ここ（公開用）に残るのは、伏せ処理を通した結果とページ、それを作るコード。
例外は兵庫県公報の写し（全文 `data/koho/full` と公告の抜粋 `data/koho/text`）で、
共通仕様9節の表で「公開できる」ものにあたり、姉妹サイトが公開 URL から読むので公開用に置く。
共通仕様9節「2本のリポジトリ」の実装。

- 走るのは公開用（この）リポジトリの Actions。金庫の Actions は止め、workflow を持たせない
  （名前が `-raw` で終わるか `-raw-` を含むリポジトリでは workflow が自分で止まる）。
  走る前に金庫が private であることも確かめる
- Actions が deploy key で金庫を `_raw/` に checkout し、`data/raw` `data/files` `data/ocr`
  `data/wayback` を `ln -s` で**今までのパスにつなぐ**。Python は置き場の違いを知らない
- 公開用への commit は**許可リスト**。公開してよいと決めたパスだけを列挙して `git add` し、
  生データ・記録・symlink が混ざっていたら止まる（鍵がある形。無い間は従来どおり `data` を丸ごと）
- しまう順番は 金庫 → 検査 → 公開用。生データを先にしまい、そこで失敗したら公開用にも送らない
- 鍵（Secret `RAW_DEPLOY_KEY`）が無いとき1本で動くのは、生データを追跡している移行前の
  リポジトリだけ。作り直した公開用で鍵が無ければ、取りに行かずに止まる

```
公開用 ogataten-nippo（public・Pages）        金庫 ogataten-nippo-raw（private）
  コード・共通仕様・all.json・parsed・         data/raw   取ってきたページ
  koho/full,text・HTML・index.json     ←ln -s→ data/files Excel・PDF
  .github/workflows（ここで毎晩走る）           data/ocr   OCR の結果
                                              data/wayback 台帳
                                              data/reports 走らせた記録
```

自動を止めたいときは `.github/workflows/shutten-recon.yml` の `schedule:` の3行を消す。

### 手元で動かす

```bash
python3 recon.py           # 全部
python3 recon.py hyogo     # 兵庫だけ
python3 recon.py osaka     # 大阪だけ
```

Python 3 だけで動く。入れるものは何もない。

## 見に行く先

一覧は `sources.json`（63件、`enabled: true` が 39件）。大店立地法の届出先は
**都道府県と政令指定都市**で、大阪府はさらに20の市町に権限を移譲しているので、
府県2・政令市3（大阪市・堺市・神戸市）・移譲市町村・八尾市と堺市の中規模（市条例）・参考の順に見ている。
どれを見ているかは about ページにも出る。

## 行儀について

相手は自治体のサーバーなので、迷惑をかけない作りにしてある。

- **robots.txt を毎回確認**し、拒否されていれば取りに行かない
- 1件ごとに5秒以上あける（`common/fetch.py` の WAIT。全部の取得がここを通る）
- 1日1回だけ
- User-Agent に運営者ページ（about）と連絡フォームの URL を入れて、誰が来ているか・どこに言えばよいかが分かるようにしている（`common/fetch.py`）

## まだやっていないこと

- 岬町の届出ページが見つかっていない（府のページに載る岬町ぶんだけ拾っている）
- 兵庫県公報の過去分は積み直しの途中（1日80号）
- 生データの置き場を金庫に移す移行（上の「2本のリポジトリ」）

## 権利まわり

- 国のオープンデータの多くは**政府標準利用規約（第2.0版）＝ CC BY 4.0 互換**で、
  出典を書けば商用利用できる。ただし**自治体は独自規約のことがある**ので、
  実際に中身を使う前に、使う自治体のページごとに1回ずつ確認する
- **数値や事実に著作権はない**ので、数字を取り込んで自分で表やグラフにするのは問題ない
- **文章表現には著作権がある**ので、本文をそのまま並べるのは避ける
- 取ってきたページそのもの（`data/raw/`）は**調べるための控え**であって、
  そのまま再公開するものではない。だから private の金庫に置く

## 取り出しと Excel（2日目に足したもの）

偵察で形が分かったので、中身を取り出すところまで進めた。

| ファイル | 中身 |
| --- | --- |
| `parse.py` | 保存ページから届出を1件ずつ取り出す。いまは兵庫県と神戸市 |
| `xlsx.py` | xlsx を読む。標準ライブラリだけで動く（入れるものを増やさないため） |
| `files.py` | ページにぶら下がっている Excel を取ってくる |
| `data/parsed/<id>/<日付>.json` | 取り出した届出 |
| `data/files/<id>/` | 落とした Excel（置き場は金庫） |

### 届出の種類は条文で分かる

| 条文 | 意味 | 使い道 |
| --- | --- | --- |
| 第5条第1項 | **新設** | 新しい大型店。8か月以上先の開店が確定情報で分かる |
| 第6条第5項 | **廃止** | 店舗面積が1000平米以下になる＝大型店でなくなる |
| 第6条 その他 | 変更 | 面積・営業時間・駐車場などの変更 |
| 第11条第3項 | **承継** | 設置者（建物の持ち主）が変わった＝建物が売買された |

「廃止」と「承継」は、表から直接とれる。PDFを開かなくてよい。

### 気をつけたところ

- 「第6条第2項（附則第5条第1項）」のように、途中に別の条文が入る書き方がある。
  条文は**先頭から**見ないと、変更を新設と読み違える
- 同じ店・同じ日に、条文ちがいの届出が同時に出ることがある（ウエステ垂水）。
  目印には条文も入れてある
- PDFは取らない。兵庫県の資料は1本8MBあり、44本で350MBになる
- `.xls`（古い形式）は落とすだけ。中がXMLではないので標準ライブラリでは開けない
