# 大店立地法ウォッチ（偵察のしかけ）

**大きなお店ができる・なくなる**ことが、開店の8か月以上前にわかる。
その情報は**4か月で公開ページから落ちる**ので、毎日とっておくと、
そのうち誰も持っていない記録になる。

これはその第一歩で、**まだ集めるところまで行っていない**。
「それぞれの県・市のページが、機械で読める形かどうか」だけを確かめる道具。

## なぜ先に偵察するのか

いきなり全部を自動で集めようとすると、たいてい最初のページで詰まる。
ページの作りが県ごとにバラバラだからで、

- **HTMLの表**で出している … いちばん楽。すぐ自動化できる
- **Excel**を置いている … 実はいちばん楽なこともある
- **PDF**を並べている … 中を読むのに一手間かかる
- **上のどれでもない** … 自分の目で見に行くしかない

のどれなのかで、作るものが変わる。先に全部の判定を出してから決める。

## 使い方

### GitHub の画面から動かす（おすすめ・パソコン不要）

1. リポジトリの **Actions** タブを開く
2. 左の「**大店立地法ページの偵察・保存**」を選ぶ
3. 右上の **Run workflow** を押す（見る場所を絞りたいときは `hyogo` か `osaka` と入れる。空なら全部）
4. 終わったら、実行結果の画面にそのままレポートが出る

**自分のパソコンでは何も動かさなくてよい。** 動かしているのは GitHub のサーバー。

あわせて**毎日朝7時（日本時間）に自動で走る**。走るたびにページの中身をそのまま
`data/raw/` に保存するので、**git の履歴がそのまま「いつ何が変わったか」の記録になる**。
差分を調べるしくみを自分で書かなくてよい。

自動を止めたいときは `.github/workflows/shutten-recon.yml` の `schedule:` の3行を消す。

### 手元で動かす

```bash
python3 shutten/recon.py           # 全部
python3 shutten/recon.py hyogo     # 兵庫だけ
python3 shutten/recon.py osaka     # 大阪だけ
```

Python 3 だけで動く。入れるものは何もない。

| パス | 中身 |

## 見に行く先（12件）

大店立地法の届出先は**都道府県と政令指定都市**。だから府県のページだけでは足りず、
**神戸市・大阪市・堺市は別に見る必要がある**。ここが抜けると一番おいしい都市部が丸ごと落ちる。

- 兵庫 … 兵庫県（縦覧状況・案内）、神戸市、尼崎市、姫路市
- 大阪 … 大阪府、大阪市、堺市（URL未確認で停止中）、高槻市、八尾市、吹田市
- 参考 … 東京都（平成12年度から20年分を公開している珍しい例。年間何件出るかの相場を見る用）

堺市はURLが見つかっていないので `sources.json` で `enabled: false` にしてある。
見つけたらURLを入れて `true` にする。

## 行儀について

相手は自治体のサーバーなので、迷惑をかけない作りにしてある。

- **robots.txt を毎回確認**し、拒否されていれば取りに行かない
- 1件ごとに2秒あける
- 1日1回だけ
- User-Agent にこのリポジトリのURLを入れて、誰が来ているか分かるようにしている

## まだやっていないこと

- **届出の中身を取り出していない。** いまはページの形を見ているだけ
- **新設・変更・廃止の区別をしていない**
- **消えた届出を検出していない。** git の履歴には残るが、拾い出すのはこれから
- 見せるページを作っていない

判定が出そろってから、上から順に作る。

## 権利まわり

- 国のオープンデータの多くは**政府標準利用規約（第2.0版）＝ CC BY 4.0 互換**で、
  出典を書けば商用利用できる。ただし**自治体は独自規約のことがある**ので、
  実際に中身を使う前に、使う自治体のページごとに1回ずつ確認する
- **数値や事実に著作権はない**ので、数字を取り込んで自分で表やグラフにするのは問題ない
- **文章表現には著作権がある**ので、本文をそのまま並べるのは避ける
- 取ってきたページそのもの（`data/raw/`）は**調べるための控え**であって、
  そのまま再公開するものではない

## 取り出しと Excel（2日目に足したもの）

偵察で形が分かったので、中身を取り出すところまで進めた。

| ファイル | 中身 |
| --- | --- |
| `parse.py` | 保存ページから届出を1件ずつ取り出す。いまは兵庫県と神戸市 |
| `xlsx.py` | xlsx を読む。標準ライブラリだけで動く（入れるものを増やさないため） |
| `files.py` | ページにぶら下がっている Excel を取ってくる |
| `data/parsed/<id>/<日付>.json` | 取り出した届出 |
| `data/files/<id>/` | 落とした Excel |

### 届出の種類は条文で分かる

| 条文 | 意味 | 使い道 |
| --- | --- | --- |
| 第5条第1項 | **新設** | 新しい大型店。8か月以上先の開店が確定情報で分かる |
| 第6条第5項 | **廃止** | 店舗面積が1000平米以下になる＝大型店でなくなる |
| 第6条 その他 | 変更 | 面積・営業時間・駐車場などの変更 |
| 第11条第3項 | **承継** | 設置者（建物の持ち主）が変わった＝建物が売買された |

「廃止」と「承継」は、表から直接とれる。PDFを開かなくてよい。

### 気をつけたところ

- 「第6条第2項（附則第5条第1項）」のように、途中に別の条文が入る書き方がある。
  条文は**先頭から**見ないと、変更を新設と読み違える
- 同じ店・同じ日に、条文ちがいの届出が同時に出ることがある（ウエステ垂水）。
  目印には条文も入れてある
- PDFは取らない。兵庫県の資料は1本8MBあり、44本で350MBになる
- `.xls`（古い形式）は落とすだけ。中がXMLではないので標準ライブラリでは開けない
