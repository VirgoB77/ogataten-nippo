## 件名

## 本文

国立国会図書館 インターネット資料収集保存事業 ご担当者さま

突然のご連絡をお許しください。
WARPに保存されている自治体の公報について、
取得の方法をご相談させていただきたくご連絡いたしました。

### 1. 私どもについて

屋号「鯨屋（くじらや）」として、行政が公表している土地に関する情報を
集めて整理し、どなたでも無料でご覧いただけるウェブサイトを運営しております。

- 大型店日報 https://ogataten-nippo.com/
  （大規模小売店舗立地法の届出を集めたサイト）

収入は掲載している広告のみで、閲覧や検索に料金はいただいておりません。
非営利団体ではございませんが、現時点で、データそのものの販売は予定しておりません。

### 2. お願いしたいこと

WARPに保存されている**大阪府公報**（waid/5120）の保存済みページを、
継続的に取得させていただけないでしょうか。
**遡れる範囲で結構です。**

将来的には、大阪市・堺市・神戸市の公報についても
同様にお願いできればと考えております。

なお兵庫県では、公報の検索用目録を年ごとのExcelで公開しておられます。
当方はそれを利用して、大規模小売店舗立地法の公告を記録しております。
大阪府についても同様の形でたどれるようにしたいと考えており、
あわせて大阪府にもご相談する予定です。

### 3. なぜお願いするのか

大阪府公報は、大阪府のウェブサイトでは当月・前月・前々月の3か月分のみの掲載です。
公報には、開発行為の工事完了公告や都市計画の決定など、
**その土地に何が起きたかを示す記録**が載っております。

3か月を過ぎると誰でも見られる形ではなくなってしまうため、
**消えてしまう前に記録として残し、後から調べられるようにしたい**と考えております。

大阪府公文書館では日付から遡ることができますが、件名から探すことが
できないため、貴館に保存されているものが、いま機械でたどれる
**ほぼ唯一の過去分**と考えております。

いただいたデータは、開発行為の工事完了公告や都市計画の決定などを
所在地ごとに整理し、出典と取得日を添えて公開する予定です。

### 4. 現在、機械での取得は行っておりません

warp.ndl.go.jp の robots.txt を確認しましたところ、
`/web/` `/20…` など保存されたページのある場所が、
ロボットに対して拒否されておりました。
そのため、**当方では一切の自動取得を行っておりません。**

ヘルプに「継続的にAPIを使う場合は使い方を知らせてほしい」とございましたので、
先にご相談させていただいた次第です。

### 5. おうかがいしたいこと

- 上記のような使い方で、取得させていただくことは可能でしょうか
- 可能な場合、どの方法（Memento API など）をお使いいただくのが望ましいでしょうか
- アクセスの間隔・時間帯・1日あたりの上限など、守るべき目安をお教えください
- 名乗り（User-Agent）に入れておくべき情報があればお教えください。
  現在は次のとおりです。

  ```
  kujiraya archive bot (kaihatsu-data; https://forms.gle/pp93tSJ5p8SAMEMk8)
  ```

  なお、同じ運営者の別サイト（大型店日報）は
  `kujiraya archive bot (ogataten-nippo; https://ogataten-nippo.com/about.html)`
  として、各自治体のウェブサイトと、Internet Archive の Wayback Machine を
  巡回しております。いずれも同時接続は1本、リクエストの間隔は5秒以上とし、
  自治体のウェブサイトについては robots.txt を毎回確認したうえで取得しております。

なお、保存されたページの著作権が元の権利者にあること、
利用にあたって権利者の許諾を得る責任が利用者側にあることは承知しております。
大阪府公報に掲載される告示・公告は著作権法第13条により著作物とならないと
理解しておりますが、あわせて大阪府にもご相談する予定です。

お手数をおかけしますが、ご検討のほどよろしくお願い申し上げます。

## 書くときに気をつけたこと

- **返信先にメールアドレスを書く。** フォームには返信できない。
  共通仕様7節の「メールは直書きせずフォーム優先」は**サイトに載せる連絡先**の話で、
  1対1の手紙は別
- **宛先を確定させてから送る。** 問い合わせフォームのURLまで書いておく
- **名乗り（User-Agent）は実物をそのまま書く。** 書いたものと実物が違うのが
  いちばんまずい。国会図書館は名乗りでアクセスを見分けるかもしれない。
  2026-09-16 に両サイトのコードを見て確かめた
- **「唯一」と言い切らない。** 大阪府公文書館に日付で引ける画像があるので、
  唯一ではない。行政機関への手紙で事実と違うことを書かない
- **巡回先を確かめてから書く。** 「自治体のサイトだけ」と書きかけたが、
  大型店日報は Internet Archive の Wayback Machine も毎日巡回していた
  （wayback.py・cron 0 22 * * *）。隠す理由がないので正直に書く。
  むしろ「他のウェブアーカイブも作法を守って使っています」と言えるほうがよい
- **作法も実物を確かめてから書く。** 間隔は両方とも5秒（WAIT = 5）。
  robots.txt を毎回見ているのは自治体のサイトのほうなので、そう書き分けた
  （web.archive.org は robots.txt が404で、そもそも制限が無い）
- **他県の前例を書く。** 兵庫県の目録を実際に使っているので、絵空事ではない
- **過去分は「遡れる範囲で結構です」。** いつからと書かないと相手が困る
- **何を作るのかを1行書く。** 出典と取得日を添えて公開する、と先に言う
- **robots.txt の拒否について、理由を推測して書かない。**
  「拒否されているため取得していません」とだけ書く
- ヘルプに書いてある手順に従っていることを示す。飛び込みではない
- 著作権の話を自分から先に書く。相手が心配する前に
- 大阪府にも同じことを相談する予定だと伝える。隠さない
- **このファイルには氏名を書かない。屋号のみ**（共通仕様7節）。
  行政あての1対1の手紙では名乗ってよいので、**送るときに運営者が1行足す**。
  置き場は public になるので、氏名はここに残さない（受付番号と同じ扱い）
- **「しない」と言い切らない。** 「販売することは考えておりません」だと、
  あとで道を狭める。「現時点で、販売は予定しておりません」にした。
  正直さは落ちないし、相手も計画が変わることは分かっている。
  **手紙で書いたことは、あとで守る**（共通仕様7節）
