# 役所に出した手紙

**この先、有料の何かを始めるときは、ここを読み返すこと。**
1年後の自分は、手紙に何を書いたか覚えていない（共通仕様7節）。

## このサイトは1通も出していない。**それでも約束はある**

**手紙は屋号「鯨屋（くじらや）」として出している。サイトごとではない。**
だから**このサイトが1通も出していなくても、同じ相手への説明として縛られる。**

正本7節「手紙は屋号で数える。サイトで数えない」。
数え方をサイト単位にすると、屋号単位の約束が見えなくなる。

## 4サイトに同じ写しを置く

1サイトにだけ置くと、ほかのサイトが「うちは出していない」と読む。
**出したのは屋号で、縛られるのも屋号。**

## 書くときの決まり

- **このファイル群には氏名を書かない。** 屋号「鯨屋（くじらや）」のみ。
  行政あての1対1の手紙では名乗ってよいので、**送るときに運営者が足す。**
- **見えないことを断定しない。** 送信時に何を入力したかは運営者しか知らない。
- 受付番号・申込番号は**この置き場に書かない。** 運営者が手元に控える。
