# 法務根拠メモ

正本3.6「公開・商品化の一般原則」が根拠にした資料を、**誰がいつ確かめたか**と、
**その資料から言えないこと**まで並べる。**リンク集にはしない。** 法務の結論を書く場所でもない
（弁護士への相談は続いている。回答が来たら、3.6 とこのメモを差分で直す）。

確かめた人の書き方は3つに分ける。混ぜない。

    PC参謀確認             PC参謀が本文を読んだ
    統括確認／PC参謀は台帳確認   統括が本文を確かめ、PC参謀は統括の根拠ソース台帳（の抜き書き）だけを読んだ
    未確認                 まだ誰も本文を確かめていない。正式な根拠には使わない

本文を丸ごと写さない。要旨と、短い語句だけにする。

## 著作権法 第12条・第12条の2・第13条

1. **発行主体**：法律（昭和45年法律第48号）
2. **資料名**：著作権法 第12条（編集著作物）・第12条の2（データベースの著作物）・第13条（権利の目的とならない著作物）
3. **URL**：https://laws.e-gov.go.jp/law/345AC0000000048
4. **確認**：PC参謀確認（2026-09-26。e-Gov 法令検索の条文を読んだ）
5. **要旨**
   - 第12条：編集物は、素材の選択又は配列によって創作性を有するものが著作物になる
   - 第12条の2：データベースは、情報の選択又は体系的な構成によって創作性を有するものが著作物になる
   - 第13条：法令、国・地方公共団体の機関などが発する告示・訓令・通達「その他これらに類するもの」、判決など、
     それらの翻訳物・編集物で国などが作成するものは、権利の目的とならない
6. **言えること**：DB・編集物の保護は、選択・配列・体系的な構成の創作性に向いている。個々の事実・数値とは分けて考える
7. **言えないこと**
   - 利用規約・契約・ほかの法令で何が禁じられているか
   - 第13条の本文に「公告」の語は無い。公報の公告が「これらに類するもの」に当たるかは、条文だけでは決められない

## 文化庁「他人の著作物を利用したい場合など」（A）

1. **発行主体**：文化庁
2. **資料名**：他人の著作物を利用したい場合など（著作権の制度解説のページ）
3. **URL**：https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/chosakukensha_fumei/
4. **確認**：PC参謀確認（2026-09-26。ページに更新日の表示は無い）
5. **要旨**：「① 著作物に当たるか？」の所で、単なる事実やデータ・アイデア・ありふれた表現など、著作物に当たらないものは許諾なく使える、と説明している。
   冒頭で、実際に使うときは著作者人格権・肖像権その他の権利・法令・利用条件なども確かめる要がある場合がある、としている
6. **言えること**：事実・データそのものの利用は、著作権の許諾の問題にはならない
7. **言えないこと**
   - 利用規約・利用条件・肖像権・ほかの法令の話を済ませてよい
   - DB をまとめて写してよい

## 二次利用の促進のための府省のデータ公開に関する基本的考え方（ガイドライン）（C の元の文と同じ文）

1. **発行主体**：各府省情報化統括責任者（CIO）連絡会議決定（平成25年6月25日。平成26年6月19日・平成27年12月24日改定）。デジタル庁のサイトに掲載
2. **資料名**：上の表題。「２ 二次利用を促進する利用ルールの在り方」の (1)・(2)
3. **URL**：https://www.digital.go.jp/assets/contents/node/basic_page/field_ref_resources/f7fde41d-ffca-4b2a-9b25-94b8a701a037/7c57e1a9/20220523_resources_data_guideline_01.pdf
4. **確認**：PC参謀確認（2026-09-26。PDF の本文を読んだ）
5. **要旨**
   - 単なる事実や数値データは、それ自体は著作物にならない
   - 編集著作物・データベースの著作物と認められる場合も、素材・数値データが著作物でなければ、
     素材・数値データそのものの利用は「著作権法の観点からは」制限されない
   - 府省は、著作物でないデータについて、著作権を理由に二次利用を制限できないことを明確にする。
     ただし、著作権以外の具体的かつ合理的な根拠で二次利用を制限する場合がありうる、と書いている
6. **言えること**：元 DB の選択・配列・体系的な構成と、個々の事実・数値を分けて考えてよい（著作権の点で）
7. **言えないこと**
   - これは**府省（国）が自分のデータを出すとき**の考え方。自治体や民間のサイトの利用条件については言っていない
   - 著作権以外の理由（利用条件・契約・ほかの法令）で制限がありうることまで否定していない
   - 元 DB を丸ごと写す設計と、事実を抜き出して独自の形に直す設計のどちらがよいかは、この文書は言っていない（それは鯨屋の設計の判断）

## 国土交通省「5－2 公開するデータの利用ルールの在り方」（C）

1. **発行主体**：国土交通省（統括の台帳による）
2. **資料名**：5－2 公開するデータの利用ルールの在り方
3. **URL**：統括の根拠ソース台帳に記録（このメモにはまだ写していない）
4. **確認**：統括確認（2026-09-26）／PC参謀は台帳確認（統括がチャットに貼った台帳の抜き書きを読んだ）。
   PC参謀はこの文書そのものを見つけられていない。上の CIO 連絡会議決定のガイドラインに、同じ趣旨の文があることは PC参謀確認
5. **要旨（統括の台帳から）**：編集著作物やデータベースの著作物と認められる場合でも、素材の単なる事実・数値データそのものは別に考える。
   素材・数値データ自体が著作物でなければ、その利用まで著作権法上当然に制限されるわけではない
6. **言えること（統括の台帳から）**：元 DB 全体の選択・配列・体系的な構成と、個々の事実・数値を分ける
7. **言えないこと（統括の台帳から）**：元 DB を丸ごと複製・再販売してよい／契約上の商用利用禁止・再配布禁止を無視できる／著作権以外の権利・法令を検討しなくてよい

## スクレイピングはどこまで許されるのか　生成AIの学習データ収集も踏まえて事業者が確認したい法的ポイント（D）

1. **発行主体**：リーガルブレスD法律事務所（大阪弁護士会。筆者の肩書は IT 弁護士。記事に「2026年4月執筆」とある）
2. **資料名**：上の表題（コラム）
3. **URL**：https://www.ys-law.jp/IT/column/column-11384/
4. **確認**：PC参謀確認（2026-09-26。本文を読んだ）
5. **要旨**
   - 「(2) どの段階で著作権の問題が生じるのか」：取得して保存する行為は複製の問題、整理・加工・データベース化は態様に応じて複製権や翻案権の問題、
     社外向けサービスや第三者への提供は公衆送信権・送信可能化権・譲渡権などの問題、と段ごとに分けている。
     適法性を取得行為だけで判断しない、としている。確認点に「社内利用にとどまるのか、外部提供まで予定しているのか」がある
   - 「利用規約・サイトポリシーとの関係」：法令だけでなく利用条件も確かめる要がある。利用規約違反は実務上の紛争の原因になりうる
   - 文章・写真・イラスト・図表・動画などには著作権が認められることがある
6. **言えること**：取得・保存・加工（DB化）・社内利用か外部提供か、を分けて検討するという整理。3.6 の「別の関所」の考え方と同じ向き
7. **言えないこと**
   - 一事務所のコラムで、判例や行政の見解ではない
   - 限定提供データ・不法行為については、この記事からは読み取れなかった
   - 個別の取得元で何ができるか

## 弁護士への質問の候補

根拠ではない。答えが出たら、上と 3.6 を直す。

- 著作権侵害に当たらない事実・数値中心の DB でも、元 DB を実質的に丸ごと模倣して競合サービスとして提供する場合に、
  不法行為その他の問題となる境界はどこか（2026-09-26・統括が質問候補として認めた）
- 自治体のサイトの「無断での複製・転用を認めない」旨の表示は、事実・数値の利用や、鯨屋の各行為（取得・private 保存・公開・商品化）に及ぶか（PC参謀の候補）
- 公報に載る「公告」は、著作権法第13条の「告示…その他これらに類するもの」に当たるか（正本3.5 の書き方の確かめ。PC参謀の候補）
