## 決まったが、作業ルール整理まで未反映のもの（一時待避所）

**ここは正式なルールの置き場ではない。**「決まったが、まだどこにも書いていない」
だけを一時的に控える場所。**チャットで言っただけでは、両方が忘れる**（冒頭のとおり）。

**いま正本へ足さない。** 正本スリム化の途中なので、足すとスリム化の対象を
自分で増やすことになる。**正本スリム化の最後に、日常作業ルール1枚へまとめる**
そのときに、3つをもう一度見る——

    ① 本当に必要か
    ② 既存ルールと重複していないか
    ③ もっと上位の原則へまとめられないか

**姉妹リポジトリへは、いま配らない。** 内容は共通でよいが、
各 repo の `.md` へ手で写すと**また二重管理になる。**
**1枚が出来てから、渡し方を決める。**

| | 何 | 中身 | 決めた日 |
|---|---|---|---|
| 23 | **commit / PR に判断者ラベルを付けない** | 通常は「統括判断」「運営者判断」のような**判断者ラベルを付けない**。**何を変えたか・なぜ変えたか**を書く。**担当者や承認者そのものを記録する必要がある場面まで禁止する意味ではない。** 過去に書いたものは**そのまま**（何をしたかの記録であって、名前の話ではない）。根拠——**札は、その人が決めた証拠にならない。** 見出しの札を確かめずに出どころ扱いして、約12本のコミットに書いた。文は途中で直されていることがある | 2026-09-22 |
| 24 | **手書きの現在値は、最新値へ交換せず、確認先だけ残す** | 対象は**生成物や元データから再取得できる、変動する現在値**。**古い値を最新値へ交換しない**（交換した瞬間からまた古くなる）。必要なら**確認先の名前だけ**残す。**日付つきの実測値は履歴なので書き換えない** | 2026-09-22 |
| 25 | **整理したことを守るためだけの専用テストは、原則足さない** | 写す場所を減らしたのだから、**見張る対象そのものが減っている。** ただし**本当に機械で守るべき安全条件に穴がある場合まで、テスト追加を禁止する意味ではない** | 2026-09-22 |
| 26 | **新しい仕組みを足す前に、既存の仕組みを減らせないか確認する** | 新しい管理場所を作る前に、先に3つを見る——**① 片方を消せないか ② 既存の情報源を参照できないか ③ 機械で確認できる現在状態を手書きしなくて済まないか。** いきなり1つの巨大な管理表にまとめない | 2026-09-22 |
| 27 | **出せる測りごとは Haiku へ出す。境目は「途中に選択が入るか」** | コードだけでなく **`.md` を読む・探す・数える作業にも効く。** **出してよい**——何を探すか・どう数えるか・どんな形で返すかが**先に決まっている**もの（見出し一覧／行数・件数／指定語の出現箇所／指定した決まりが何節に出るか／行番号参照など形式の決まった抽出／複数の `.md` を横断した候補の一覧化／こちらが決めた基準での一次の振り分け）。**出さない**——途中に**選ぶ・意味を決める**が入るもの（検索語そのものを選ぶ／同じ意味か別の軸かの判断／最終の分類／残す価値の判断／削って安全かの判断／**下請けの結果をそのまま正式な測定として採ること**）。**出した結果は鵜呑みにしない。**正式な測定・判断に使う前にこちらで確かめる。役割——**下請けは候補を集める・数える・並べる／こちらは確かめる・意味を決める・実装する／統括はそもそも必要か・もっと減らせないかを見る。** 根拠は 2026-09-22 の実測——方法が固定された測り（行数・節ごとの件数・またがる節の数）は**3本とも使えた**が、「ふさわしい鍵語を選んで重複を判定する」は**結論が使えず、こちらで取り直した** | 2026-09-22 |
| 28 | **正本7節から外した、日常作業ルールの回収候補** | 7節を現在の仕様だけに縮めたときに外した論点。**全文は正本の git 履歴にある。ここには題だけ置く**——①**個人のメールアドレスが履歴に無いことの確かめ方**（ファイルの中身と作者欄は別の場所で、同じ探し方では両方見えない／浅いクローンと遅れた枝では「無い」が嘘になる／**「無い」と書くときは、どの範囲で見て無いのかも書く**）②**手紙を出すときの作法**（言い切らずに「現時点で」を付ける／フォームに氏名欄があればそこに入れる／送信控えの持ち方／robots.txt はホスト名まで書く／名乗りは実物のまま書く）③**収益設計**（訪問数で測らない・記録は日数で増える・年に数件で成り立つ値付け。**本体は `docs/keikaku.md` に在る**） | 2026-09-23 |
