## 【サイト固有の現在ルール】

街頭窃盗統計だけに効く決まり。**共通の決まりは本文にあり、ここには書かない**（各項の終わりの § が、その本文）。
各項の〔〕は、第1版の元の行（原文は下の【実例・実測・経緯】にある）。

- **扱うのは、警察庁が「街頭犯罪」と呼ぶ分類の窃盗の部分、7手口だけ**
  （ひったくり・車上ねらい・自動車盗・オートバイ盗・自転車盗・部品ねらい・自動販売機ねらい）。
  侵入盗（空き巣）は街頭犯罪ではないので入らない〔旧 295-305〕
- **名前は警察の言葉にそろえる。「屋外窃盗」（造語）と「盗難」（被害者側の言葉）は使わない**〔旧 306-308〕
- **ひったくりと自動販売機ねらいは、町丁目では出さず市区町村に上げる。**
  車上ねらい・部品ねらい・オートバイ盗・自動車盗は「車・バイク」の1層にまとめる〔旧 785-792〕
  （種別をまとめる・粒度を上げる決まりは本文 §3.2）
- **率の計算は、画面（JS）と Python で同じ入力を当てて突き合わせる検査を置く**
  （件数7 × 人口6 の42通り。`node` の無い環境では skip として出す）〔旧 5826-5830〕
  （画面の値と機械の値を1か所から出す決まりは本文 §9）

### 街頭窃盗統計という名前について

警察庁が「街頭犯罪」と呼んでいる分類の、窃盗の部分そのもの。
扱う7手口は、ひったくり・車上ねらい・自動車盗・オートバイ盗・自転車盗・
部品ねらい・自動販売機ねらい。実データで確認ずみ（罪名は窃盗のみ、手口は7つだけ）。

**侵入盗（空き巣）は街頭犯罪ではないので、最初から入っていない。**
データが欠けているのではなく、そういうデータ。名前がこれを先に説明する。

出どころが警察のデータなので、名前も警察の言葉にそろえる。
「屋外窃盗」は造語なので使わない。「盗難」は被害者側の言葉で、
警察の統計は「窃盗」「認知件数」なので使わない。

街頭窃盗統計の実物（兵庫県・8年・849町丁目。実数を出せた区画の割合）：

    まとめる前   車上ねらい 47.1% ／ 部品ねらい 27.6%
                 オートバイ盗 21.2% ／ 自動車盗 2.9%
    まとめたあと 「車・バイク」の1層で 69.7%

    ひったくり 0.7% と 自動販売機ねらい 6.7% は、まとめても足りないので
    市区町村に上げた（町丁目では出さない）
