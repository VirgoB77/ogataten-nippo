**同じ告示の中で、地番と氏名が並んでいる。**

    ❌ 列名で当てる      列が無い
    ✅ **節の見出しで当てる**（「開発許可を受けた者の…」）

**番号（「２」）では当てない。** 号によって節の番号は変わりうる。
**見出しの語**で当てる。番号は、当たった節がどこまで続くかを見るのに使う。

#### 節が違うものを、混ぜない

上の紙には**住所が2つ**ある。混ぜると2通りに壊れる。

    開発区域の地番        その土地の場所。**出してよい**（法人のとき）
    許可を受けた者の住所   **法人なら本店。個人なら住んでいる場所**

混ぜると、法人の**本店所在地を開発地として出す**（中身が違う）。
個人なら、**住んでいる場所を出す**（3.1 で出してはいけないもの）。

2026-09-19、用途地域（国土数値情報 A29）を落とせた。中身は市区町村ごとの
**多角形の地図**（`.shp` / `.dbf` / `.prj` / `.shx`）だった。
**住所では引けない。座標が要る。**

    届出の住所  →  ？  →  緯度・経度  →  多角形のどれに入るか  →  用途地域
                  ↑ ここが無い

座標に直すには位置参照情報（町丁目の代表点）が要る。
**そしてそれは、4節②の町丁目一覧そのもの。** 別々に追いかけていた2つが、
