# 競売だけの細部（共通仕様の第1版から分けたもの）

このファイルは、旧正本（`docs/kyotsu-shiyo.md` 第1版）の原文を、**書き換えずに**行の範囲ごとに写したもの。
決まりとしては読まない。**いま効いている決まりは `docs/kyotsu-shiyo-v2.md`**（案。移行検査が済むまでは旧正本）。
各段の頭の〔〕に、旧の行・旧の節・新しい本文の行き先を書いた。

**競売の置き場へ移すのは、第2版に切り替えるとき。** それまではここに置く（共通の決まりではないが、消さない）。

**〔旧 540〜540 行｜旧の節：法人だけの升は、1件でも伏せない ＞ ⚠️ これができるのは、**個票を全部出しているサイトだけ**｜サイト別｜共通の本文：一般の決まりは本文に残した〕**

**競売統計（`records` が空）では、この例外を使わない。**

**〔旧 5743〜5745 行｜旧の節：9. 技術方針（共通） ＞ 合計が変わらない壊れ方は、合計の検査では捕まらない｜サイト別｜共通の本文：一般の決まりは本文に残した〕**

競売統計が踏んだ（2026-09-19）。過去データを入れると、升が
`公告-新規` から `公告-再公告` に**裏返る。**
だが**親（公告）の合計は変わらない**ので、「升の合計＝見た行の数」は通る。

**〔旧 5750〜5751 行｜旧の節：9. 技術方針（共通） ＞ 合計が変わらない壊れ方は、合計の検査では捕まらない｜サイト別｜共通の本文：一般の決まりは本文に残した〕**

街頭窃盗統計も同じ形を書いている——「区画そのものが減ったとき。
**両方が同時に減れば釣り合う**」。

**〔旧 6032〜6038 行｜旧の節：9. 技術方針（共通） ＞ 守りを入れる日に、その守りが止めるものが、まだ要ることがある｜サイト別｜共通の本文：本文には無い〕**

2026-09-19、競売統計で起きた。収集用は**置き場**。収集用の Actions は止め、
workflow は持たせない。その守りが「名前が `-raw` で
終わるか `-raw-` を含むリポジトリでは workflow が自分で止まる」。競売統計には
まだ入っていなかった。ところがその日、金庫がまだ唯一の集め手だった。金庫の名前は
既に `-raw` で終わっていて、公開用の Actions は鍵が未了で動かせない。素直に入れると、
その晩の巡回がその1行で止まる。裁判所の入札物件は消えるので、**止めた日のぶんは
永久に取れない**（3.5「巡回の頻度が、そのまま記録の完全性になる」）。

**〔旧 6057〜6059 行｜旧の節：守りを入れる日に、その守りが止めるものが、まだ要ることがある ＞ 例外には3つ要る｜サイト別｜共通の本文：本文には無い〕**

止まるものだけが残り続けない。競売統計では、印が公開用の木に混ざったら、
公開用の木を作るスクリプトが中断する形にした（印が届くと、公開用でも
自己停止が素通りするため）。

**〔旧 6063〜6063 行｜旧の節：守りを入れる日に、その守りが止めるものが、まだ要ることがある ＞ 例外には3つ要る｜サイト別｜共通の本文：本文には無い〕**

いまは `.github` が公開用の許可リストに無いので、この経路は一度も通らない。

**〔旧 6098〜6098 行｜旧の節：守りを入れる日に、その守りが止めるものが、まだ要ることがある ＞ 例外が消えたあとの姿を、置いた日に試す｜サイト別｜共通の本文：本文には無い〕**

`run:` の本文を取り出し、名前と印を入れ替えながら実際に走らせる。

**〔旧 6110〜6110 行｜旧の節：守りを入れる日に、その守りが止めるものが、まだ要ることがある ＞ 期限つきの例外を置いてよいのは、あとから直せる守りだけ｜サイト別｜共通の本文：本文には無い〕**

金庫で Actions が走るのは置き場の形の話で、あとから直せる。取れなかった晩は直せない。
