# 旧→新の対応表（共通仕様 第1版 → 第2版）

第1版（`docs/kyotsu-shiyo-v2/dai1han.md`。2026-09-27 に第2版へ切り替える前の正本）の**見出し全部**と**全行**が、どこへ行ったかの表。「旧 N 行」は dai1han.md の行。第2版の本文は `docs/kyotsu-shiyo.md`。
扱いの意味：

    KEEP          ほぼそのまま本文に残した
    COMPRESS      言い方を詰めて本文に残した（同じ意味の言い直しを、本家の節への参照にしたものも含む）
    MOVE_HISTORY  経緯として docs/kyotsu-shiyo-v2/rireki.md へ（原文のまま）
    MOVE_SITE     1つのサイトだけのものとして docs/kyotsu-shiyo-v2/site-*.md へ（原文のまま。現在ルールか実例かに分けた）
    MOVE_NOKORI   未決・未測定として docs/nokori.md へ（原文は nokori-genbun.md）

行の表ではさらに、DUP（同じ意味・同じ条件が本家の節にあるので参照にした）、
SPLIT_HISTORY／SPLIT_SITE（決まりは本文に残し、同じ行の経緯・サイトの細部は原文のまま写した）を使う。
扱いは書き手の申告ではなく、**本文に同じ文言で残ったかを機械で見て**付け直した（KEEP と申告しても言い換えがあれば COMPRESS、経緯へ移しても一般則が本文にもあれば SPLIT_HISTORY）。
見出しの表の「意味の変更」は、その見出しの下の行の表の申告から決めた（2つの表を食い違わせない）。
site-*.md は【サイト固有の現在ルール】（決まりとして効く）と【実例・実測・経緯】（決まりではない）に分けてある。
表の行き先の `site:ogataten` などは、`docs/kyotsu-shiyo-v2/site-ogataten.md` などのこと（本文では `site-ogataten.md` と書く）。
