# 大阪市のファイルについて

大阪市のサーバーは、この仕組みからの取得に 404 を返す（URLの組み立ては正しく、
ブラウザからは落とせる）。ここにある5本は 2026-09-12 に利用者がブラウザで
落としたものを、そのまま置いた。

| ファイル | 中身 |
| --- | --- |
| `ju_20260818.xlsx` / `.pdf` | 縦覧一覧。いま縦覧中の届出（R8-1〜R8-29）と、店舗概要（設置者・小売業者・面積・駐車台数・営業時間） |
| `to20260630.xls` | **届出一覧。平成12年6月の法施行から大阪市に出た全届出、届出日順。1,421件** |
| `si20260630.xls` / `.pdf` | 市内店舗一覧。いま大阪市にある大型店を区別に。340件 |

大阪市はこのページのデータを **CC-BY 4.0** で提供すると明記している
（https://www.city.osaka.lg.jp/keizaisenryaku/page/0000373985.html ）。
出典を書けば再配布・加工・商用利用ができる。

`.xls` は古い形式で、標準ライブラリでは開けない。読むには xlrd が要る。

## 更新のしかた（人の手が要る）

機械で取る手は 2026-09-12 に二つ試してどちらも 404 だった（参照元ヘッダーを添える、
ページを先に開いてクッキーを持った状態で取る）。名乗りを偽って取る手は使わない。
大阪市オープンデータポータル（data.city.osaka.lg.jp）も GitHub Actions からは応答が無かった。

なので大阪市だけは、次の手順で人が更新する。

1. 大阪市のページに新しいファイル名（例: `to20260930.xls`）が出ると、
   毎日の実行の `files-report.md` と Actions の要約に
   **「新しいファイル名 … がページに出ています」** と太字で出る。
2. ブラウザでそのファイルを落として、このフォルダに同じ名前で置く（古いものは残してよい）。
3. 次の実行で `parse_excel.py` が新しい方を読む。

毎日 3 本を取り直しているので、サーバー側が通すようになれば `files-report.md` に
「取り直せた」と出て、その日から自動に切り替わる。
