# 大阪市のファイルについて

大阪市のサーバーは、この仕組みからの取得に 404 を返す（URLの組み立ては正しく、
ブラウザからは落とせる）。ここにある5本は 2026-09-12 に利用者がブラウザで
落としたものを、そのまま置いた。

| ファイル | 中身 |
| --- | --- |
| `ju_20260818.xlsx` / `.pdf` | 縦覧一覧。いま縦覧中の届出（R8-1〜R8-29）と、店舗概要（設置者・小売業者・面積・駐車台数・営業時間） |
| `to20260630.xls` | **届出一覧。平成12年6月の法施行から大阪市に出た全届出、届出日順。1,421件** |
| `si20260630.xls` / `.pdf` | 市内店舗一覧。いま大阪市にある大型店を区別に。340件 |

大阪市はこのページのデータを **CC-BY 4.0** で提供すると明記している
（https://www.city.osaka.lg.jp/keizaisenryaku/page/0000373985.html ）。
出典を書けば再配布・加工・商用利用ができる。

`.xls` は古い形式で、標準ライブラリでは開けない。読むには xlrd が要る。
